Introduction

What Is Behavioral Biometrics?

Behavioral biometrics refers to the automated recognition of individuals based on their physical characteristics and behavioral patterns. Unlike traditional authentication (passwords, PINs, tokens), biometric systems verify who you are — not just what you know or have.

This system combines two authentication layers: (1) knowledge-based verification via a password, and (2) biometric verification via facial recognition — providing multi-factor authentication (MFA) without the need for external devices or tokens.

🧠
Physiological Biometrics

Static physical traits: face geometry, fingerprints, iris patterns, retinal scans, and DNA. These are permanent and universal.

📈
Behavioral Biometrics

Dynamic behavioral patterns: keystroke dynamics, mouse movement, gait analysis, typing rhythm, and cognitive patterns.

Technical Deep Dive

How Face Authentication Works

Facial recognition in this system uses a convolutional neural network (CNN) pipeline to extract a 128-dimensional descriptor vector from a face image. Authentication is performed by computing the Euclidean distance between the live face descriptor and the stored enrollment template.

01
Face Detection

The Tiny Face Detector (a lightweight MobileNet-based CNN) scans each video frame to locate face bounding boxes with a confidence score. Only faces with confidence > 65% proceed.

02
Landmark Extraction

68 facial landmark points are identified — eyes, nose, mouth corners, jaw contour, and eyebrows. These are used to normalize the face crop and align it for recognition.

03
Descriptor Generation

A FaceNet-style ResNet-34 CNN processes the aligned face image and outputs a 128-dimensional floating-point vector (face descriptor) that uniquely encodes the person's facial geometry.

04
Template Averaging (Enrollment)

During registration, 5 frames are captured and their descriptors are averaged. This reduces noise from lighting variation and head pose, creating a robust enrollment template.

05
Euclidean Distance Matching

At login, the live descriptor is compared to the stored template using Euclidean distance. A distance below 0.50 confirms identity (same person); above 0.50 rejects access.

Privacy & Ethics

Privacy Considerations

This system is designed with privacy as a core principle. All biometric data is processed and stored entirely on the client device using browser localStorage. No facial images are ever transmitted to a server. Only the 128-number descriptor vector is stored — it is computationally infeasible to reconstruct a face image from this vector.

Privacy Guarantees
  • Zero server-side data transmission
  • No facial images stored — only abstract descriptor vectors
  • Descriptors cannot reconstruct original facial data
  • Session tokens expire after 1 hour
  • All data cleared on browser storage reset
FAQ

Frequently Asked Questions

What if the lighting changes between registration and login? ▼
The system averages 5 frames during enrollment to create a robust template. For best results, ensure consistent lighting. If matches fail, re-register under your typical lighting conditions.
Can someone use a photo to spoof the system? ▼
This demo system does not include liveness detection. A production deployment should add liveness checks (blink detection, head movement, depth sensing) to prevent photo attacks. This is a known limitation of purely 2D face recognition.
Where is my biometric data stored? ▼
All data is stored locally in your browser's localStorage. Nothing is sent to any server. You can clear all data by clearing your browser's local storage for this page.
What is the 128-dimensional face descriptor? ▼
The face descriptor is a 128-element floating-point vector produced by a deep neural network. Each number encodes abstract geometric and textural features of the face. The same person's descriptor is consistently similar across captures, while different people produce very different descriptors.
What happens if face verification fails? ▼
You can retry face verification up to 20 frames. If it still fails, you can re-register your face profile. This ensures authorized users are never permanently locked out.
